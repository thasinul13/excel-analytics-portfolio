# Excel Analytics Portfolio

Business analysis projects built in Microsoft Excel, using retail and supermarket data.

Each project starts with a real business question, then shows how I cleaned the data, analysed it, and what I found. Screenshots are included in every folder, so you can see the work without downloading the files.

## Projects

| # | Project | Business question | Skills used |
|---|---------|-------------------|-------------|
| 01 | [Supermarket Sales](01-supermarket-sales) | Which stores and categories drive the most sales? | Tables, sorting, filtering, formulas, pivot tables |

## Skills covered

- Data cleaning (sorting, filtering, removing duplicates, text functions)
- Formulas: SUM, AVERAGE, COUNTIFS, SUMIFS, IF
- Lookups: XLOOKUP
- Pivot tables and pivot charts
- Charts and conditional formatting
